02 — Execution

Local-first, remote only on request

The Task Dispatcher routes each task to a worker. V1 ships the LocalWorker only; the interfaces exist so RemoteWorker slots in without a rewrite.

LocalWorker · default
Task → Android app → Agent Core →
Search / HTTP / headless browser /
terminal / download → internet
on-device · no server · background via Android scheduler
RemoteWorker · opt-in
Task → encrypted session → user-
controlled / trusted worker → agent
runtime → headless browser → internet
explicit consent · sensitive data never silently sent

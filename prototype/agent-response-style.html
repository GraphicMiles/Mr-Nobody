Three collisions worth deciding before this becomes Dart

1 · Hover does not exist on a phone. ToolChips reveals each row's chevron on group-hover/row and opens the diff preview on onMouseEnter. On Android those affordances would simply never appear, and the diff preview would be unreachable. Every hover-gated control has to become either always-visible or tap-toggled. Above, the chevron is always drawn and rows expand on tap.
2 · The palette is monochrome by charter. app_theme.dart says "one accent (white), near-black surface tiers, hairline borders, no shadows". The library uses green/red for diffs and coloured dots per source. Mr Nobody has exactly one non-grey — the amber already used for the figure warning. Recommendation: keep it that way. Reserve amber for "something needs your judgement" and express everything else with weight and position. A palette with one warning colour makes that colour mean something; a palette with four makes it decoration.
3 · The library's verbs are for a coding agent. Write 204 lines, file diffs, npm run freeze. Mr Nobody's agent searches, reads pages, downloads and clicks. The row shape is right and the taxonomy is not: Search · Read · Download · Click · Type, mapping directly onto the tools already registered. The diff-chip row has no counterpart — the closest equivalent is a downloaded-files strip, which is worth having but is a different component.

What can be built now, and what cannot

  • Trace, loader, actions, sources, follow-ups — all buildable today. TaskEventStore already records tool.call, tool.result, tool.denied with timings, and taskEvents is already on the method channel with no Dart caller.
  • The blur-in stream is not. AiProvider.complete() returns one finished string and both remote providers buffer the whole body. Word-by-word arrival needs a token callback, stream:true, SSE parsing and an EventChannel.
  • Honest interim: stream the trace from the event log, then reveal the finished answer with the same stream-in blur applied per word on a timer. It is the library's animation over a non-streamed payload — real motion, no pretence of live tokens, and it becomes genuinely live when the provider work lands with no UI change.
  • Favicons need care. Fetching them from source domains is an un-gated network call per result, straight through the privacy audit's egress rule. Either route via NetworkGate or draw a lettermark from the domain — the mark above is drawn, not fetched.

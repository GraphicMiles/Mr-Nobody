What's proposed

NEW controls that the core already supports but were never surfaced: Privacy mode (Normal / Private / Nobody), Proxy (route + host + port), Data Saver (Off / Balanced / Aggressive / Extreme), Search engine, Approval mode, and Block ads & trackers / Strip parameters toggles.

MOVED Data Saver currently lives only in the hidden dev panel (ⓘ → BENCH); this promotes it to a first-class Settings section.

Design decisions to confirm:

  • Privacy mode as a 3-way segmented control (not a popover) — it's a core identity, not a one-off choice.
  • Data Saver as a 4-way segmented control with tiny one-word summaries.
  • Proxy is a form inside a card (route dropdown + host/port fields) rather than a popover.
  • Search engine / approval mode / theme use the existing popover pattern (consistent with profile & provider).
  • Blocking & parameter-stripping sit under Browsing as toggles, on by default.

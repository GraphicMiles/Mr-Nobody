How Mr Nobody Gets Work Done

Deterministic software with explicit human checkpoints. Never invents facts, never leaks context.

01 / PARSE

Tier-0 Fast Path

Device clock, arithmetic calculations, and direct single actions are handled locally on-device. No network call is made, and no AI tokens are consumed.

02 / EXTRACT

Structure Over Dumps

Transport noise, HTML tags, undecoded entities, and menu rails are stripped before sentences are scored. The engine ranks candidate facts specifically against question intent.

03 / EXECUTE

User Approval Gate

Consequential actions — like initiating large file downloads, writing to storage, or connecting to external endpoints — pause for your explicit confirmation.

Extractive, Cited Synthesis

Ask a question or provide web pages. Mr Nobody reads the primary sources, removes boilerplate noise, and delivers verified answers anchored to real citations.

Three Modes. One Rule: Fail Closed.

When a promised privacy route is unavailable, Mr Nobody refuses to silently fall back to cleartext.

MODE 01

Normal Mode

Standard browsing through your current connection with native ad and tracker blocking enabled. Browsing history is turned off by default.

MODE 02

Private Mode

Reduced local retention with isolated cookie jars and stronger sandboxing when supported by the installed Android WebView engine.

MODE 03

Nobody Mode (Tor)

Routes all traffic through Orbot SOCKS5 or the bundled Tor service. If the proxy terminates, the NetworkGate halts all outbound traffic.

Frequently Asked Questions

Clear answers on architecture, privacy guarantees, and open source integrity.

What exactly is Mr Nobody?

An open-source Android browser with an on-device deterministic agent for research, page extractions, and reliable downloads. Both browser and agent share identical privacy configurations and network routing.

Does Mr Nobody run a local Large Language Model (LLM)?

No. The on-device agent is purely deterministic code. It parses queries, strips markup noise, scores candidate sentences against question intent, and generates structured citations. This guarantees zero hallucinations and fast battery-efficient answers.

Does it require an account or subscription?

No. There is no account, no sign-in, and no profile. You install the APK and it works immediately.

What data ever leaves my device?

By default, only the requests required to fetch the web pages you visit. Version checks send minimal version metadata. If you choose to configure an optional remote AI provider (Gemini, Groq, OpenAI), task context leaves the device only for those explicit agent tasks.

How does Nobody Mode enforce fail-closed privacy?

When Nobody Mode is active, all socket egress is bound to the configured Tor or Orbot proxy. If the proxy terminates or drops, the NetworkGate halts all outbound requests rather than silently failing open to cleartext.

Why does Mr Nobody have its own download engine?

Android's native DownloadManager lacks robust HTTP range verification, custom Storage Access Framework folder selection, and fails on unstable networks. Mr Nobody's engine supports pause, resume, retries, and landing-page link resolution.

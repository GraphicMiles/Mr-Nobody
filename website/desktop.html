Architecture & Workflow

How Mr Nobody gets work done.

The agent is deterministic software with strict boundaries. It does not hallucinate answers or act secretly in the background.

01 / PARSE & CLASSIFY

Tier-0 Fast Path

Device clock, arithmetic calculations, and single-step direct actions are handled entirely on-device by deterministic code. No network egress, no AI tokens consumed.

02 / EXTRACT & CITE

Structure Over Dumps

Transport noise, HTML tags, undecoded entities, and site-menu rails are purged before sentences are scored. The engine ranks candidate facts based on what the question specifically requested.

03 / GATE & EXECUTE

User Approval Gate

Consequential actions — like initiating large downloads, saving files to storage, or connecting to external endpoints — pause and require your explicit tap before execution.

Engineered For Performance

Built for people who want more from the web.

A browser should be a high-performance tool, not an advertising conduit. Every layer in Mr Nobody is built to keep the interface fast and private.

Extractive, Cited Research

Ask a question or provide URLs. Mr Nobody reads primary sources, cleans out markup noise, scores relevance, and returns structured answers with clickable citations.

Local Ad & Tracker Blocker

High-efficiency on-device ad and analytics filter lists prevent cross-site redirects, block pop-up networks, and strip tracking tokens (?utm, ?fbclid) from URLs.

App-Owned Download Engine

Independent of Android's system DownloadManager. Supports custom Storage Access Framework folders, validated HTTP range resumption, and persistent notifications.

Instant Tab Surface

Invisible frame stabilizer keeps Android WebView surfaces active after page loads, permanently eliminating stale black screens and frame tear.

Fail-Closed Privacy Routes

Choose between Normal, Private, or Nobody (Tor / Orbot) mode. If your configured privacy proxy disconnects, the network gate halts rather than leaking traffic.

Crash & Process Resilience

Designed around Android process lifecycle. Resumes active tasks, downloads, and tab states cleanly following OS background kills without repeating side effects.

Deterministic Intelligence

An agent with boundaries.

Mr Nobody's local task agent is deterministic code, not a bulky on-device language model. It searches, extracts, ranks, and verifies facts with plain, auditable logic — and always pauses for confirmation before consequential operations.

Read Agent FAQ

Tier-0 Local Fast Path: Device clock, arithmetic, and direct tasks resolved locally with 0 network calls.

Extractive Sentence Ranking: Classifies query intent (figure, person, definition) and scores sentences specifically.

Markup & Noise Sanitization: Strips scripts, JSON-LD schema, menu rails, and HTML entities prior to citation.

Rendered WebView Extraction: Falls back to rendered DOM extraction when plain HTTP responses lack dynamic content.

App-Owned Downloads: Direct integration with the built-in HTTP range resumption engine.

Android WorkManager: Runs scheduled recurring monitoring checks reliably across system reboots.

Optional Remote AI: Gemini, Groq, or OpenAI-compatible endpoints can be enabled manually. Task context leaves the device only then, while tool execution stays strictly under local gate policy.

Frequently Asked Questions

Questions? Clear answers.

Everything you need to know about Mr Nobody's privacy model, local agent, and download architecture.

What exactly is Mr Nobody?

An open-source Android browser featuring an on-device deterministic agent for research, structured page extractions, and reliable downloads. Both browser and agent share identical privacy configurations and network routing.

Does Mr Nobody run a local Large Language Model (LLM)?

No. The on-device agent is purely deterministic code. It parses queries, strips markup noise, scores candidate sentences against question intent, and generates structured citations. This ensures instantaneous answers without high battery consumption or hallucinations.

Does it require an account or subscription?

Never. There are no accounts, sign-ins, user profiles, or cloud databases. You download the APK, install it, and it works immediately.

What data ever leaves my device?

Only the network requests required to fetch the web pages you visit. Version checks send minimal version metadata. If you choose to configure an optional remote AI provider (Gemini, Groq, OpenAI), task context is transmitted to that provider only during explicit agent tasks.

How does Nobody Mode enforce fail-closed privacy?

When Nobody Mode is active, all socket egress is bound to the configured Tor or Orbot proxy. If the proxy process terminates or disconnects, the NetworkGate halts all outbound requests rather than failing open to cleartext.

Why does Mr Nobody have its own download engine?

Android's native DownloadManager lacks robust HTTP range verification, SAF custom folder support, and fails when connections drop on cellular networks. Mr Nobody's engine supports pause, resume, retries, and landing-page link resolution.

How are plain http:// pages treated?

Mr Nobody enforces HTTPS by default. Insecure cleartext HTTP triggers a strict "Load anyway / Cancel" warning. Insecure file downloads present an explicit Continue/Reject prompt, protecting your Referer headers.

Is Mr Nobody really 100% open source?

Yes, licensed under MIT. Every push is validated by 1,028 Java tests, 185 Flutter widget tests, and 14 privacy auditor tests in continuous integration.

How do I verify the downloaded APK?

You can run sha256sum mr-nobody-1.0.7.apk and match the output against the hash provided on this page and in update.json. Android's package installer also validates the cryptographic certificate signature on install.

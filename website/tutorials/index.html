Implementation note

Real physics where it matters.

Rigid bodies, collisions and constraints use Matter.js. Interface choreography uses Motion’s hardware-accelerated transforms and physical springs. Liquid and typographic concepts use Anime.js spring curves. All three libraries are pinned and vendored locally, so the previews work without a CDN.
